# ООО «КЛАС» — комплексное промышленное снабжение

Одностраничный представительский сайт (лендинг) компании комплексного промышленного снабжения ООО «КЛАС» (г. Оренбург).

## Структура проекта
- `index.html` — единственный файл сайта: разметка, стили (Tailwind CSS через CDN) и интерактивность (нативный JavaScript)

## Локальный запуск
```bash
npm run dev
```
Сайт будет доступен по адресу: `http://localhost:3000`
